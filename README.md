# Monitoring Service

Скрипт мониторинга доступности сервисов: асинхронно опрашивает список URL по HTTP, проверяет код ответа, логирует результат через loguru (в консоль и в файл `logs/monitoring.log`) и при ошибке имитирует отправку уведомления в Telegram (`print`).

По умолчанию проверяются два фиктивных адреса (`formit.fake`, `leadsync.fake`, доменов не существует, поэтому проверка всегда падает с ошибкой соединения) и два рабочих сайта (Ozon, Avito) для примера успешной проверки.

## Запуск

Нужен Python 3.12 и uv.

```
uv sync
uv run main.py
```

В консоли появится лог проверки каждого сервиса, тот же лог запишется в файл `logs/monitoring.log`. При ошибке дополнительно выводится строка `Send alert to Telegram: ...`, имитирующая уведомление.

## Модули

Проект разбит по одному файлу на задачу.

`settings.py`: настройки приложения через pydantic settings (путь к логам, таймаут запроса, заголовки запроса).

`dto.py`: `ServiceConfig`, описание одного проверяемого сервиса (имя и url).

`services.py`: список `SERVICES`, какие сервисы проверяются.

`models.py`: `CheckResult`, результат одной проверки и форматирование строки лога.

`logging_setup.py`: настройка loguru, вывод в консоль и в файл с ротацией.

`checker.py`: класс `Checker`, делает HTTP запрос через aiohttp и превращает ответ или ошибку в `CheckResult`.

`notifier.py`: класс `Notifier`, имитирует отправку уведомления об ошибке.

`monitor.py`: класс `Monitor`, опрашивает все сервисы параллельно, логирует результаты и вызывает `Notifier` при ошибке.

`main.py`: точка входа, собирает модули вместе и запускает один цикл проверки.
